# Auto Repair-shop Scheduling Optimizer

This repository contains the implementation of a Mixed-Integer Linear Programming (MILP) model for optimizing daily schedules in automobile repair shops. 
The model focuses on minimizing the total cost of idle time and overtime across repair stations. 
The optimization is developed using Google OR-Tools and includes a web-based interface for demonstration.
Default parameters are based on the case study instance with four repair stations as described in the related research article.
